# 两场景固定协议实验报告

日期：2026-10-08｜库：ChronoGuard 0.1.0｜最终运行：outputs/algolib/checked_release_20261008

## 结论先行

**工程封装与可复用接口已完成，但检测效果有限；目前不能声称跨领域可靠检出、原创算法突破或生产安全可用。**
电池数据只支持正常留出误报评价，SMD 是 3 台机器的逐点基线。尺度退化修正发生在已经查看相同测试数据结果之后，因此最终结果属于开发复验，不是全新盲验。

## 1. 固定协议与输入边界

- 四方法全部报告：robust、LOF、Isolation Forest、PCA；q99、连续 5 窗、seed42。
- 训练数据按时间顺序 60% 拟合 / 20% 校准 / 20% 验证；最多 6000 拟合窗，拟合侧按时间顺序均匀抽样。校准/验证/测试不抽样。
- 中心、MAD 与退化回退标准差只使用拟合侧；阈值只使用独立正常参考校准分数。
- 验证段只报告报警比例，不用它自动选择模型。测试标签不进入模型拟合、阈值校准或参数选择。
- 预测连续 5 窗超阈值才从第 5 窗起确认，不回填之前 4 窗；没有 point adjustment。
- 电池：正常包 6/8/9/10 共 26508 窗，原始缓存形状 (N,256,20)，取 0,2,...,14 的 8 个电压通道，peer 特征；四包轮流留出，其他包各自按时间分段。
- 电池缓存是已构造窗口。缺少原始时间戳/步长，未独立证明相邻训练/校准窗口不共享原始采样点；不能宣称已排除全部原始点级泄漏。留出测试包与训练包不同。
- SMD：machine-1-1、machine-2-1、machine-3-1 分别拟合/校准/测试，合计 80873 个测试点；T=1、C=38、independent 特征。
- T=1 时除均值外的 independent 时序统计量为零；本实验是逐点基线，不是复杂时序模型验证。
- SMD 训练段正常性是参考假设，没有训练异常标签独立核实。3 台机器不代表完整 28 台。
- 下载字节身份与来源见 provenance.json 及本地 download_manifest.json；交付不包含数据。

## 3. SMD：严格逐点与事件指标

所有逐点指标使用 confirmed，FPR=FP/(FP+TN)，分母为正常点。事件由连续阳性标签定义；事件内至少一次确认就算检出，但不修改逐点预测。
事件延迟只统计已检出事件，单位为测试采样点，不是秒；未检出事件不能算作零延迟。

### 同一方法的三机器宏平均

宏平均是同一固定方法在三台机器上各指标的算术平均；F1 列是三台 F1 的均值，不是从宏平均 Precision/Recall 再计算的 F1。
未挑选各机器测试最优方法拼接成绩，也不据此宣布一种方法在全部场景最优。

| robust | 0.7352 | 0.3723 | 0.2436 | 9.573% |
| lof | 0.3401 | 0.4732 | 0.2379 | 15.977% |

## 4. MAD 退化根因与开发复验

首次运行发现：稀疏变化特征可能具有零 MAD，但并非恒定。直接使用原电池尺度下限 1e-7 会把这种特征的正常变化放大。
先建立复现测试，再修改拟合侧尺度：MAD < 1e-7 且拟合标准差 >= 1e-7 时回退到拟合标准差；否则按 MAD 并设 1e-7 下限。三个 SMD 机器回退特征数分别为 3/7/4。

修正不读取测试标签，也未改变 q99、连续5窗或随机种子；但是开发者已经看过同一测试数据上的初始结果。**不能称为一次全新未见测试集盲验。**
并非所有方法/指标都改善，常量/极小尺度及漂移问题仍存在。未来需要冻结源码后在新的独立数据上评价，不能继续围绕这一测试集调参后把结果包装为盲验。

### 交付前两项工程契约修正

1. **PCA 阈值边界的分块不一致：** 原 BLAS 投影/重建随批大小出现浮点舍入差异；最小复现中严格超阈值判断导致整段与逐窗报警不同。先保留失败回归，再用 `np.einsum(..., optimize=False)` 固定逐行投影和重建归约。没有添加阈值容差、分数舍入或回填报警；回归同时核对与原 PCA 数学结果的一致性。另完成 45 组分块压力检查；不承诺跨硬件/运行时逐位一致。
2. **SMD 离线缓存绕过清单：** 先复现标签文件修改后未被拒绝的缺陷，再使 `load_smd` 在存在下载清单时，无论在线或离线都核对来源、三类文件清单项与 SHA256；无清单的手工输入仍只做格式校验。未改动真实数据或清单。

修正后的源码在 `checked_release_20261008` 重新执行全部 28 组实验。与复核前 `release_20261008` 相比，28 组公开检测/误报/事件指标完全一致；4 组 PCA 校准阈值有约 1e-16 量级差异，运行耗时也不同。这是工程契约修正，不是检测性能提升证据；历史运行及失败复现仍保留。
