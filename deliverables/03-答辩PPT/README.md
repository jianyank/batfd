## 两处预计被追问的地方，建议提前准备口径

1. **创新性偏弱**。作品自我定位是「不主张新算法，只做流程复用」。答辩时应把讨论引向
   **§4.3 的距离对比度诊断机理**——它虽不是新算法，但是一个可迁移的复用预检方法，且是实测得出的。
2. **应用效果偏弱**。SMD 宏 F1 仅 0.11–0.29，电池无真实召回率。建议主动说明
   「效果我们是差的，但差在哪、为什么差，我们有量化机理」，把问题从"效果好不好"
   转到"能否诊断出为什么不好"。
