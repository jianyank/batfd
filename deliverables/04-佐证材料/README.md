## 匿名化提醒（这一份风险最高）

专利证书、软著证书、论文首页、获奖证书等**通常自带学校名称或指导教师姓名**，而规则要求匿名化。

- 处理前先确认：遮挡后是否影响证明效力
- 若影响，考虑询问组委会如何处理，不要盲目遮挡
- 本项目拟用的证据（测试日志、哈希清单）**不含身份信息**，风险较低

## 注意

- 本项目**不得**把未发表的材料、外部草稿或来源不明的文件作为佐证
- 佐证内容必须与技术方案中已陈述的事实一致，不要额外主张技术方案里没有的效果
