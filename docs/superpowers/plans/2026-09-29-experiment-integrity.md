1. 隔离与记录：核对 README、现有消费者，建立分支并保存本计划和分步日志。

3. 产物：建立可审计的实验清单，将新表写入独立实验目录；参数变更单独命名；P6–P9 校验缓存来源，P10 显式选择实验，旧表只在明确允许历史模式时读取，不静默混用。
4. 口径：统一 alarm_ever、early_detected；无起点时 early_detected 为 None，等于起点不算提前；起点前触发率与轨 A 真虚警率明确区分。保留注明语义的旧接口/表格兼容，不修改历史 CSV。
5. 综合验收：标准库回归、临时数据端到端冒烟、CLI 帮助和语法检查、核对历史 outputs 与 main 未变。每步追加实际结果到 docs/changes/2026-09-29-experiment-integrity.md 并分步提交。
