# 当前研究体系

本目录保留正常数据建模的 LOF-Peer 离线研究候选。算法与评分协议未因仓库整理而改变。

- 任务定义与完整方法：`MENTOR_REPORT.md`（LaTeX源：`MENTOR_REPORT.tex`）。
- 精简方案及已有数值：`BEST_SCHEME.md`。
- 安装、缓存输入、实验和预测命令：`USAGE.md`。
- 无监督推理与事件级评价的边界：`REAL_ACCEPTANCE.md`。
- 汇总结果及封存来源说明：`results/README.md`。

15种原始输入候选由 `methods.py` 中 `RAW_METHODS` 固定；可选冻结深度特征重放只读取历史特征，不训练深度网络。普通实验与核心回归测试均不依赖旧 `batfd/` 框架。

训练数据无故障，近故障测试片段不可直接整段标阳性。真实近故障推理尚未完成，异常分数不是故障概率，单体排序不是故障原因证明；`deployment_approved=false`。

历史 `runs/`、审计日志、旧设计文档与旧报告已归档到仓库外，当前仓库不附带模型或私有数据。文档中的研究结果属于此前完成的实验，不是公开目录下载后已具备的运行产物。
