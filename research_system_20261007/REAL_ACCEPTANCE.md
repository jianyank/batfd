# 无监督推理与真实事件评价边界

## 1. 已确认的任务前提

训练数据保证无故障，测试数据由接近故障的片段构成。拟合与阈值校准只使用正常数据；**无监督推理不需要故障标签**。正常训练留出包的报警应视为正常数据误报，不再表述为“健康状态未知”。

近故障片段不能直接整段标为故障，故障后的每个窗口也不要求全部报警。异常分数、超阈值、连续确认报警与真实故障事件是不同概念。

## 2. 推理前必须明确

- 输入来源、数组哈希、包ID、通道顺序、数据域与有限值；不能未经核实改通道或单位。
- 固定模型、标准化参数、正常校准阈值、连续5窗规则、单体证据计算及源代码哈希；不依据测试结果回调阈值。
- 包边界、缺测断点、序列初始化和状态传递；独立片段不共享状态。
- TestData1有43个完整窗口与训练缓存逐值重复，应标记并给出剔除重复后的分析；窗口步长及部分重叠仍待核实。

## 3. 无事件标签时可报告什么

逐包展示异常分数与正常校准阈值、超阈值和确认报警位置、可疑单体证据排序。时间映射未确认时仅用窗口索引，不换算分钟/小时/天；没有确认故障单体时不计算真实定位准确率。上述分析不必等到事件标签齐备，但不能据此称真实故障已经检出。

## 4. 有外部记录后如何评价

| 评价项 | 所需独立记录 |
| :---: | :---: |
| 事件检出 | 事件ID、包ID、故障时间或区间、证据来源及事先定义的判定区间 |
| 提前量/延迟 | 故障时间与窗口起止时间的可信对应关系 |
| 单体定位 | 已确认故障单体及确认依据，预先约定取排名的时刻 |
| 正常误报 | 正常区间定义；时间频次还需有效暴露时间 |

事件表应记录来源与可信度，允许未知区间与区间起点，不使用模型自身分数或合成注入标签充当真实事件证据。先定义报警合并/解除、允许时间容差、Top-1/Top-3和失败门槛，再看最终测试结果。事件检出不等于要求故障后每个点都判阳性。

## 5. 当前状态与不适用范围

已完成缓存规模、重复窗口及时间数组的准备核查；三份近故障测试缓存已完成固定模型推理、逐窗分数与报警及单体偏差证据分析，共69216窗、14包。按描述性1.5倍时间差中位数缺口规则重置后确认21568窗，不重置时为27339窗；物理连续性仍未确认。事件级真实故障性能尚未评价。正常包8/10高报警、共同变化抵消、缓漂移和初始异常仍是已知限制。

当前交付为离线研发候选，不用于现场自动安全控制、故障概率输出或无需人工核验的维修决策。任何算法/阈值修改另立版本、重新封存；合成压力测试与真实事件评价分开报告。
